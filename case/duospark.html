Case study

DuoSpark: AI date planning for couples

Plans a weekly date both partners pick, hosts video-call dates with a live AI voice, and turns photos into a narrated memory.

LiveMVP with every AI feature working

Problem

Long-distance couples talk every day but rarely do anything together; calls turn into check-ins, and date ideas assume you're in the same room. Busy couples living together fall into the same routine for the same reason: planning takes effort.

Users

Starting with long-distance couples in India, who already date on video. Couples living together, newly married couples and couples outside the metros come next.

My role

Found the problem, wrote the PRD, built and shipped the app with AI-assisted development, and wrote the pitch for the Google AI Startup Buildathon India 2026.

Key decisions

  • Both partners swipe privately; only a match becomes a date, so no one has to guess or carry the planning.
  • Gemini with Google Search grounding finds real places in the couple's city; fixed rules filter by location so it never suggests the wrong city.
  • The Gemini Live host joins only when the couple starts it, through short-lived tokens, so the API key never reaches the browser.
  • Every AI feature has a backup model list and a simple non-AI fallback.

What I'm measuring next

No users yet. The validation plan: survey 100 couples, run a 4-week pilot with 50, compare hosted and unhosted dates, and test a ₹99/month premium price.

Known gaps

  • No traction data yet; the pilot comes first.
  • Gemini Live audio is the biggest cost, so premium caps hosted dates.

Tools

Gemini API (Flash, vision, text-to-speech), Google Search grounding, Gemini Live, WebRTC, Supabase (Postgres and auth), Vercel.
