Publish with GitHub + Vercel

This is a static-site workflow with no database and no server-side admin login. Changes you make here are saved in this browser as a draft. To publish them for everyone, click Export site data, upload the downloaded portfolio-data.json to your GitHub repository replacing the existing file, and commit the change. Vercel will redeploy automatically.

  1. Open the live site with ?admin=1.
  2. Add/edit projects and companies below.
  3. Click Export site data and save the downloaded JSON.
  4. In GitHub, open portfolio-data.json → Edit (pencil) → replace its contents with the downloaded file → Commit changes.
  5. Vercel automatically deploys the update. Refresh the live site to verify.
